## 1) لماذا نعيد التصميم أصلاً

### الشاشة الرئيسية — `DashboardScreen.kt` (797 سطراً)

عشرة أقسام متتالية، كلٌّ منها يطالب بالانتباه **بنفس القوة**:

```
0 إعلانات · 1 إنقاذ السلسلة · 2 دليل البدء · 3 الورد اليومي · 4 خطة اليوم
5 المذاكرة العاجلة · 6 دروس اليوم · 7 لافتة الحالة · 8 قصة اليوم · 9 عبارة اليوم
```

**المشكلة:** حين يصرخ كل شيء، لا يُسمع شيء. لا توجد إجابة بصرية فورية
لسؤال «ماذا أفعل الآن؟».

### الودجت — `widget_zmastery.xml`

تخطيط **عمودي** داخل ودجت **عريض** (`4×2` خلايا):

```
🔥 الشعلة  →  حبة الحالة  →  الاقتباس (weight=1)  →  شريط الهدف  →  الزر
```

**المشكلتان:**
1. العرض المتاح مُهدر — كل عنصر مضغوط في شريط ضيق رغم اتساع الودجت.
2. الاقتباس يبتلع أكبر مساحة، وهو **العنصر الوحيد الذي لا يُعلّم شيئاً**.

## 2) السياق الشخصي — قيود تصميمية لا تفاصيل عاطفية

| الواقع | ما يعنيه للتصميم |
|--------|-------------------|
| **445 يوماً** متواصلة في دولينجو حالياً | الشعلة تعمل كمحفّز — لا تُلغِها |
| **100 يوم ضاعت** سابقاً ثم انتكاسة طويلة | أي ضغط إضافي على «لا تكسر السلسلة» = **خطر لا ميزة** |
| **«لا أشعر أنني حققت تقدماً كبيراً»** | ⭐ الشكوى المركزية — التصميم يجب أن يُظهر **إتقاناً** لا **أياماً** |
| دقيقتان يومياً لحفظ الشعلة | التطبيق يكافئ الفهم، لا الحضور |

> **المبدأ الحاكم:** عدّاد الأيام يقيس *الحضور*. المطلوب مقياس يقيس *التعلّم* —
> كلمات متقنة، مستوى CEFR، دقة. أرقام لا تنمو إلا بالفهم.

### 📱 المجموعة الثانية — الودجت (4 صور)

> ⚠️ **قيد تقني حاسم:** الودجت يُبنى بـ`RemoteViews` التي **لا تدعم**:
> الحلقات الدائرية · التدرجات المعقدة · الرسوم المتحركة · Compose.

#### الصورة 5 — «القيادة المدمجة»
من التكديس الرأسي إلى ثلاثة أعمدة أفقية.

```
┌──────────┬───────────────────────────┬────────┐
│    🔥    │  وسم عربي صغير            │  ⏱ 🎯  │
│   ١٤٦    │  ▓▓▓▓▓▓░░░░  ٣/٥          │        │
│   يوم    │  ● ● ● ● ● ○ ○            │ [ابدأ] │
└──────────┴───────────────────────────┴────────┘
```
- خلفية: تدرّج نيلي قطري `#4148B8 → #5B62D6`
- فاصلان رأسيان خفيفان بشفافية 20%
- العمود الأيسر ~30% · الأوسط ~45% · الأيمن ~25%
- شريط التقدم تركوازي بأطراف دائرية وتوهج خفيف عند رأسه
- سبع نقاط أسبوع: 5 ممتلئة بيضاء، 2 مفرغة
- توهج دائري خافت ينزف من الزاوية العلوية اليمنى

#### الصورة 6 — «حلقة التقدم»
حلقة دائرية كبيرة تحمل الرسالة كلها.

```
┌─────────────┬────────────────────────┐
│      ◯      │  🔥 ٢٦٠  كلمة          │
│   حلقة ٦٥%  │  عنوان عربي عريض       │
│   رقم ضخم   │  [شريحة] [شريحة]       │
│   في مركزها │  [زر عريض متدرج]       │
└─────────────┴────────────────────────┘
```
- خلفية داكنة `#1B1D2A` بتوهج نيلي شعاعي خلف الحلقة
- الحلقة: تدرّج تركوازي→أخضر، سُمك سخي، أطراف دائرية، نقطة مضيئة عند رأس القوس
- اليسار ~38% · اليمين ~62%
- دوائر متحدة المركز خافتة جداً تشعّ من الحلقة

#### الصورة 7 — «كلمة اللحظة»
الودجت **يُعلّم** بدل أن يُذكّر فقط.

```

- زر الصوت: دائرة بخلفية بيضاء شفافة، بحجم هدف لمس حقيقي

- الشعلة تتراجع لزاوية صغيرة — **مقصود**

#### الصورة 8 — «الطقم المتكيّف»

```

- خلفية موحّدة: تدرّج نيلي `#4148B8 → #5B62D6`

### ⚠️ تنبيه إلزامي للوكيل المولِّد

نماذج توليد الصور **لا تُجيد كتابة العربية** — ستُنتج خربشات بلا معنى.
هذا **مقبول ومتوقع**، ويجب **ذكره صراحةً** عند تسليم الصور:

> «النصوص العربية في الصور مشوّهة وبلا معنى. قيّم **التخطيط والأحجام
> والألوان والتسلسل البصري** فقط، وتجاهل كل كلمة ورقم.»

**لا** تحاول إصلاح النص العربي بتوليد متكرر — أهدرٌ للوقت. النصوص الحقيقية
تأتي عند التنفيذ من بيانات التطبيق.

### 📊 المطلوب مع الصور

سلّم مع كل صورة:
1. **اسم التصور** وفكرته الحاكمة في سطر واحد.
2. **جدول** يربط كل عنصر بالبيانات الحقيقية في الكود (انظر القسم 4).
3. **عيب واحد صريح على الأقل** لكل تصور — لا تبِع كل شيء كأنه مثالي.
4. **مخاطر تقنية** إن وُجدت (خاصة لودجت `RemoteViews`).

## 4) قيود التنفيذ — اقرأها قبل البناء

> هذه للوكيل الذي **سينفّذ** التصميم المختار، لا للذي يولّد الصور.

### 4.1 البيانات المتاحة فعلاً في الكود

| ما تعرضه الواجهة | المصدر الحقيقي |
|-------------------|-----------------|
| الشعلة · الدروع · XP | `vm.engagement.streak` · `vm.wallet.streakFreezes` · `vm.xp` |
| المهمة التالية | `vm.activeDailyTasks.firstOrNull { !it.done }` |
| تقدم الخطة | `vm.activeTasksDone` / `vm.activeDailyTasks.size` |
| الكلمات المتقنة | `vm.masteredCount` من أصل `vm.activeVocab.size` |
| الدروس المكتملة | `vm.completedLessons` |
| مراجعات اليوم | `vm.totalReviewsToday` مقابل `vm.dailyGoal` |
| الدقة | `vm.accuracy` |
| مستوى CEFR | `Telemetry.estimatedCefr(masteredCount, completedLessons, lifetime.examAvg)` |
| نشاط الأسبوع | `vm.dayStats` (مفتاحها `epochDay`) |
| الكلمات المستحقة | `vm.dueWords` (FSRS) |
| كلمات على وشك النسيان | `vm.forgottenWords` |
| بيانات الودجت | `ProgressStore.load(context)` — جسر SharedPreferences |

### 4.2 نظام التصميم القائم — استخدمه ولا تخترع بديلاً

```
الألوان   ui/theme/Color.kt      → ZIndigo · ZCyan · ZEmerald · ZAmber · ZRose
                                    ZTextPrimary · ZTextSecondary · ZTextMuted · ZBorder
                                    (كلها تتبدّل تلقائياً بين الفاتح والداكن)
الأبعاد   ui/theme/Dims.kt       → ZRadius (XS..XL, PILL) · ZSpace (شبكة 4dp) · ZSize
المكونات  ui/components/Common.kt → SoftCard · SectionTitle · حلقة تقدم جاهزة
```

### 4.3 قواعد صارمة

1. **لا شاشة جديدة لأي محتوى** — راجع [`docs/BLOCKS_GUIDE.md`](../docs/BLOCKS_GUIDE.md).
2. **الودجت `RemoteViews` فقط** — لا Compose، ولا Canvas إن أمكن تجنّبه.
   الحلقة الدائرية تتطلب `Canvas→Bitmap→setImageViewBitmap` وهو **أثقل**
   وقد يُبطئ التحديث على الأجهزة الضعيفة. هذا سبب كافٍ لتفضيل الأشرطة.
3. **`minSdk = 24`** — تجنّب أي API أحدث دون فحص.
4. **الوضعان الفاتح والداكن** يعملان — استخدم رموز `Z*` لا ألواناً ثابتة.
5. **لا تحذف الاقتباس اليومي من التطبيق** — إن أُزيل من الودجت فهو باقٍ في
   `DailyPhraseCard` على الرئيسية.
6. **الاحتفال بالإتقان قبل الأيام** — إن أضفت لحظة احتفال، اجعل النص الأكبر
   «+12 كلمة» لا «446 يوماً». الأول يُستعاد دائماً، والثاني يُفقد مرة واحدة
   إلى الأبد. (السبب في [`docs/ideas/README.md`](../docs/ideas/README.md))

### 4.4 ⚠️ شرط التحقق — غير قابل للتفاوض

**لا تدفع كوداً لم تتحقق من أنه يُبنى.**

```bash
./gradlew assembleDebug        # يجب أن ينجح
./gradlew testDebugUnitTest    # يجب أن ينجح
```

إن كانت بيئتك بلا JDK أو Android SDK، **قل ذلك صراحةً قبل أن تكتب سطراً**،
واعرض البدائل: فتح PR ليبنيه CI، أو الاكتفاء بالتوثيق.

> توازن الأقواس وتطابق معرّفات `R.id` **ليست تحققاً** — إنها فحص إملائي.
> هذا الشرط أُضيف بعد حادثة حقيقية في هذا المشروع.
