# الجزء الثاني — الودجت (4 تصورات)

الوضع الحالي: `widget_zmastery.xml` — تخطيط **عمودي** داخل `4×2` خلايا:
شعلة → حبة حالة → اقتباس (يأخذ `weight=1`) → شريط هدف → زر.

**المشكلة:** الاقتباس يبتلع أكبر مساحة، والعناصر مكدّسة رأسياً في ودجت **عريض** —
إهدار للعرض المتاح، وكل عنصر يصير ضيقاً.

---

## 1️⃣ القيادة المدمجة — `widget-1-compact.jpg`

**التغيير الجوهري:** من التكديس الرأسي إلى **ثلاثة أعمدة أفقية**.

```
┌──────────┬─────────────────────────┬────────┐
│   🔥     │  المهمة التالية          │  ⏱ 🎯  │
│  446     │  ▓▓▓▓▓▓░░░░  3/5         │        │
│  يوماً    │  ● ● ● ● ● ○ ○           │ [ابدأ] │
└──────────┴─────────────────────────┴────────┘
```

- ✅ يستغل العرض بدل إهداره · معلومات أكثر بنفس الحجم
- ✅ **نقاط الأسبوع السبع جديدة** — تُظهر النمط لا الرقم فقط
- ✅ كل شيء ممكن بـ`RemoteViews` — لا مخاطرة تقنية
- ⚠️ يفقد الاقتباس (أو ينتقل للحجم الكبير)

---

## 2️⃣ حلقة التقدم — `widget-2-ring.jpg`

**التغيير الجوهري:** حلقة دائرية كبيرة تحمل الرسالة كلها.

- ✅ الحلقة تُقرأ من بعيد أسرع من أي شريط
- ✅ أجمل التصاميم الأربعة بصرياً
- 🔴 **عقبة تقنية حقيقية:** `RemoteViews` **لا تدعم** الحلقات الدائرية أصلاً.
  الحل: توليد صورة الحلقة برمجياً (`Canvas` → `Bitmap` → `setImageViewBitmap`)
  عند كل تحديث. ممكن، لكنه **أثقل** وقد يبطئ التحديث على الأجهزة الضعيفة.

---

## 3️⃣ كلمة اللحظة — `widget-3-word.jpg`

**التغيير الجوهري:** الودجت **يُعلّم** بدل أن يُذكّر فقط.

```
┌────────────────────────────────────┐
│ 🔥 446        [مؤمَّن]           ↻ │
│                                    │
│  water                        🔊   │
│  /ˈwɔːtə/                          │
│  ماء                               │
│                                    │
│ ▓▓▓▓░░░░░░  مراجعة · كلمات · درس   │
└────────────────────────────────────┘
```

- ✅ **أقوى فكرة تعليمياً** — كل نظرة للهاتف = تعرّض للكلمة
- ✅ يستفيد من `VocabWord` و FSRS الموجودَين: **اعرض الكلمة المستحقة للمراجعة**
- ✅ يتكامل مع صوت `dictionaryapi.dev` (الفكرة 04)
- ⚠️ الشعلة تتراجع لزاوية صغيرة — وهذا **مقصود وجيد**

---

## 4️⃣ الطقم المتكيّف — `widget-4-adaptive.jpg`

**التغيير الجوهري:** ثلاثة أحجام بلغة تصميم واحدة.

| الحجم | المحتوى |
|-------|---------|
| `2×2` | شعلة + رقم + شريط رفيع |
| `4×2` | تخطيط التصور 1️⃣ |
| `4×3` | 4×2 + قسم الكلمة من 3️⃣ |

- ✅ الأكثر احترافية — يحترم أن المستخدمين يغيّرون الأحجام
- ✅ `zmastery_widget_info.xml` يدعم `resizeMode` **بالفعل**
- ⚠️ **ثلاثة أضعاف العمل** — 3 تخطيطات + منطق اختيار حسب المقاس
