# الجزء أ — فيديو/رسوم الحماسة بعد الدرس

## أ.1 ما هي

اللحظة التي تُنهي فيها درساً في دولينجو فتظهر احتفالية: دُوو يرقص، الشعلة
تشتعل، الأرقام تقفز. هذه اللحظة **مصمَّمة بعناية** — هي جزء من سبب العودة غداً.

## أ.2 لماذا تعمل نفسياً

| العنصر | الوظيفة |
|--------|---------|
| فوريّة المكافأة | يربط الجهد بالمتعة قبل أن يتبدد الشعور |
| حركة وصوت | يُرسّخ الذاكرة العاطفية للحظة |
| إظهار الرقم يقفز | يجعل التقدم **مرئياً** لا مجرداً |
| قِصَر المدة (2–4 ثوانٍ) | يكافئ دون أن يُملّ أو يُبطئ |

## أ.3 التنفيذ المقترح — **رسوم لا فيديو**

> **قرار مبدئي: لا تستخدم ملف فيديو.**

| الأسلوب | الحكم |
|---------|-------|
| ملف MP4 | ❌ حجم كبير · مشغل ثقيل · لا يتكيف مع اللون/الوضع الليلي |
| Lottie (JSON) | 🟡 ممتاز، لكن يضيف اعتمادية جديدة |
| **Compose Animation** | ✅ **المقترح** — لا اعتمادية · يتبع نظام الألوان · خفيف · قابل للتخصيص |

المشروع يستخدم Compose بالكامل بالفعل، وفيه `Animatable` و`Transition` جاهزان.

### تصميم مقترح: `LessonCompleteCelebration`

```
        ✨   🔥   ✨
      شعلة تنمو من 0 → الحجم الكامل
           ↓
      «445 → 446»  رقم يعدّ تصاعدياً
           ↓
      +12 كلمة جديدة   ⭐ +50 XP
           ↓
      جسيمات تتصاعد وتتلاشى
           ↓
      [ متابعة ]     ← تخطٍّ فوري بلمسة
```

**عناصر تقنية:**
- `AnimatedVisibility` + `scaleIn`/`fadeIn` للدخول
- `animateIntAsState` لعدّاد الأرقام
- `Canvas` بسيط للجسيمات (~30 نقطة تتصاعد وتتلاشى)
- صوت قصير من `res/raw/` — **الملفات موجودة فعلاً**:
  `notify_success.wav` · `notify_streak.wav`
- **مهرب فوري:** أي لمسة على الشاشة تُنهي الاحتفال

### أين يُوصل

`LessonBlockKind.ACTIONS` (زر «إكمال الدرس») موجود بالفعل →
يُستدعى الاحتفال عند نجاح الإكمال. لا بلوك جديد ولا شاشة جديدة.

## أ.4 مخاطر وضوابط

| الخطر | الضبط |
|-------|-------|
| يصير مزعجاً بعد المرة العاشرة | ≤ 2.5 ثانية · تخطٍّ بلمسة · مفتاح إيقاف في الإعدادات |
| يُبطئ الأجهزة الضعيفة | جسيمات معدودة · بلا صور نقطية · احترام `minSdk 24` |
| يضخّم قلق «لا تكسر السلسلة» | ⚠️ **احتفِ بالإتقان (كلمات · دقة) قبل الأيام** |

> **ملاحظة تصميمية مهمة:** بالنظر إلى انتكاسة الـ100 يوم، اجعل النص الأكبر
> في الاحتفال هو **«+12 كلمة»** لا **«446 يوماً»**. الرقم الأول يمكن استعادته
> دائماً؛ الثاني يُفقد مرة واحدة إلى الأبد. هذا فرق نفسي حاسم.

## أ.5 الحكم

✅ **فكرة جيدة · تكلفة منخفضة · تنفَّذ متى شئنا.**
مرشّح ممتاز لأول ميزة بعد انتهاء الإصلاحات الأساسية.

# الجزء ب — مزامنة التقدم من دولينجو

## ب.1 ما فُحص فعلاً (2026-09-02)

### ❌ لا توجد واجهة رسمية

لا تنشر دولينجو أي API عامة للمطورين، ولا توثيقاً، ولا مفاتيح.
الطلب متكرر في منتدياتها منذ سنوات دون استجابة.

### ✅ لكن يوجد endpoint عام يعمل — اختبرته الآن

```
GET https://www.duolingo.com/2017-06-30/users?username={USERNAME}
```

**ناتج حقيقي من الاختبار (الحساب الرسمي `duo`):**

```json
{"users":[{
  "id": 952,
  "username": "duo",
  "name": "Vincent",
  "streak": 0,
  "streakData": { "currentStreak": null },
  "totalXp": 5889,
  "fromLanguage": "en",
  "learningLanguage": "ja",
  "currentCourseId": "DUOLINGO_JA_EN",
  "courses": [
    { "id":"DUOLINGO_JA_EN", "title":"Japanese",
      "learningLanguage":"ja", "fromLanguage":"en",
      "xp":2340, "crowns":9999 },
    { "id":"DUOLINGO_ES_EN", "title":"Spanish", "xp":916, "crowns":9999 }
  ],
  "hasPlus": true,
  "creationDate": 1323472652
}]}
```

**الحقائق المؤكَّدة:**
- ✅ يعمل **بدون مصادقة** — لا كلمة سر ولا توكن
- ✅ اسم المستخدم فقط كافٍ
- ✅ يُرجع: الشعلة · إجمالي XP · كل الكورسات مع XP والتيجان · تاريخ الانضمام
- ⚠️ يقبل أيضاً البحث بالبريد — وهذه هي الثغرة التي أثارت جدلاً أمنياً سابقاً
- ⚠️ عليه **حدود معدل** أضافتها دولينجو بعد حادثة تجميع البيانات
- ⚠️ `2017-06-30` ليس تاريخاً عشوائياً — إنه إصدار داخلي غير موثّق قد يختفي

### ما يُعطيه وما لا يُعطيه

| متاح ✅ | غير متاح ❌ |
|---------|------------|
| الشعلة الحالية | الوحدة/الدرس الحالي بالتحديد |
| إجمالي XP | قائمة الكلمات التي تعلمتها |
| XP لكل كورس | محتوى الدروس |
| التيجان لكل كورس | الأخطاء وأنماطها |
| تاريخ الانضمام والاسم | XP اليومي مفصّلاً بالتاريخ |

## ب.2 ما نرفضه صراحةً

| الطريقة | لماذا نرفضها |
|---------|--------------|
| `duolingo-api` (اسم مستخدم + **كلمة سر**) | ❌ إدخال كلمة سر دولينجو في تطبيق ثالث = خطر أمني غير مقبول. **لن يحدث.** |
| توكن JWT من الكوكيز | ❌ ينتهي بسرعة · استخراج يدوي معقّد · يمنح صلاحيات كتابة لا نحتاجها |
| نقاط الكتابة (`PUT /sessions`) | ❌ **غش صريح** — يزوّر XP. يناقض هدف التطبيق من أساسه |
| خدمات وسيطة (وسطاء يقرؤون الحساب) | ❌ لا داعي لطرف ثالث لمعلومة عامة أصلاً |

## ب.3 التصميم المقترح — لو نفّذناها

> **مبدأ حاكم:** قراءة فقط · عام فقط · اختياري · لا يكسر شيئاً عند فشله.

```kotlin
// data/DuolingoPublicStats.kt  (مقترح — غير موجود)

data class DuoStats(
    val username: String,
    val streak: Int,
    val totalXp: Int,
    val courses: List<DuoCourse>,
    val fetchedAt: Long,
)

// الضوابط الإلزامية:
//  · اسم المستخدم فقط — لا حقل كلمة سر في الواجهة إطلاقاً
//  · مرة واحدة كل 6 ساعات كحد أقصى (احترام حدود المعدل)
//  · كاش محلي في DataStore — يُعرض عند فشل الشبكة
//  · فشل الطلب = لا شيء يظهر، لا رسالة خطأ مزعجة
//  · مفتاح تعطيل في الإعدادات
//  · وسم واضح في الواجهة: «مصدر غير رسمي — قد يتوقف»
```

### أين يظهر

بطاقة صغيرة في `DashboardScreen` بجانب شعلة Z-Mastery:

```
┌──────────────────┬──────────────────┐
│  🔥 Z-Mastery    │  🦉 Duolingo     │
│     23 يوماً      │     446 يوماً     │
│  142 كلمة متقنة  │   12,450 XP      │
└──────────────────┴──────────────────┘
```

**القيمة الحقيقية ليست الرقم** — بل المقارنة: أن ترى «446 يوماً» بجوار
«142 كلمة متقنة» يذكّرك أي الرقمين يقيس التعلّم فعلاً.

## ب.4 المخاطر

| الخطر | الشدة | الملاحظة |
|-------|-------|----------|
| يختفي الـendpoint بلا إنذار | **عالية** | غير موثّق — قد يُغلق في أي لحظة |
| حظر بحدود المعدل | متوسطة | 6 ساعات بين الطلبات يكفي لحساب واحد |
| مخالفة شروط الخدمة | منخفضة–متوسطة | قراءة بيانات **حسابك أنت** العامة، استخدام شخصي |
| تعقيد بلا فائدة تعليمية | **عالية** | ⚠️ عدّاد جميل لا يُعلّم كلمة واحدة |

## ب.5 الحكم

⚠️ **ممكن تقنياً · منخفض القيمة التعليمية · هشّ.**

**الترتيب المقترح:** آخر القائمة. الفكرة 01 (التأسيس) والفكرة 02 (الوحدة)
تغيّران **كيف تتعلم**. هذه تغيّر **رقماً على شاشة**.

**لو أردناها رغم ذلك:** ابنِها في ساعة واحدة كبطاقة قراءة فقط، بلا مصادقة،
وبتوقّع صريح أنها قد تتوقف. لا تبنِ عليها أي منطق أساسي في التطبيق.
