## 1) ✅ dictionaryapi.dev — مُختبَر ويعمل

**الرابط:** `https://api.dictionaryapi.dev/api/v2/entries/en/{word}`
**بلا مفتاح · بلا تسجيل · بلا حد معلن**

### الناتج الحقيقي (اختبار `water` — 2026-09-02)

```json
[{
  "word": "water",
  "phonetic": "/ˈwoːtə/",
  "phonetics": [
    { "text": "/ˈwɔːtə/",
      "audio": "https://api.dictionaryapi.dev/media/pronunciations/en/water-uk.mp3",
      "license": { "name": "BY 3.0 US" } },
    { "text": "/ˈwɔtəɹ/",
      "audio": "https://api.dictionaryapi.dev/media/pronunciations/en/water-us.mp3",
      "license": { "name": "BY-SA 3.0" } }
  ],
  "meanings": [{
    "partOfSpeech": "noun",
    "definitions": [{
      "definition": "A substance (of molecular formula H₂O) found at room temperature…",
      "example": "By the action of electricity, the water was resolved…"
    }]
  }],
  "license": { "name": "CC BY-SA 3.0" },
  "sourceUrls": ["https://en.wiktionary.org/wiki/water"]
}]
```

### 🎁 المفاجأة: يعطي **صوتاً بشرياً حقيقياً**

لم يكن هذا متوقعاً. الحقل `audio` يعطي MP3 لنطق بشري مرخَّص —
**بريطاني وأمريكي منفصلين**. هذا يعني:

| اليوم | مع هذه الواجهة |
|-------|----------------|
| كل صوت كلمة = طلب Gemini TTS | الكلمات الشائعة = صوت بشري مجاني |
| يستهلك الحصة | صفر استهلاك |
| صوت اصطناعي | صوت إنسان حقيقي |

**الاستراتيجية المقترحة:** جرّب هذه الواجهة أولاً؛ فإن لم تجد الكلمة أو
لم يكن لها صوت، فارجع إلى Gemini TTS. تسلسل احتياطي بسيط يوفّر حصة كبيرة.

### أين يدخل في التطبيق

| الحقل | الاستخدام |
|-------|-----------|
| `phonetic` | يملأ `VocabWord.phonetic` تلقائياً — بلا Gemini |
| `audio` | مصدر صوت أول قبل TTS |
| `definition` | تعريف إنجليزي في بطاقة المفردات |
| `example` | مثال طبيعي جاهز |

### ⚠️ الضوابط الإلزامية

```kotlin
// كاش دائم — الكلمة تُطلب مرة واحدة في العمر
//  · التطبيق فيه TimedCache في PerformanceUtils.kt (للذاكرة)
//  · وTtsManager يخزّن الصوت في cacheDir/z_audio (نمط جاهز للاقتباس)
//  · القاموس يحتاج كاشاً *دائماً* على القرص، لا مؤقتاً
// الترخيص CC BY-SA 3.0 → يجب ذكر المصدر (Wiktionary) في شاشة «حول»
// خدمة يديرها متطوعون → تعامل مع الفشل بصمت، لا تُظهر خطأً
```

## 2) ✅ Datamuse — مُختبَر ويعمل

**الرابط:** `https://api.datamuse.com/words?...`
**بلا مفتاح · 100 ألف طلب/يوم مجاناً**

### ناتج حقيقي (2026-09-02)

```
GET /words?sl=ship&max=8          ← sl = يشبهه صوتياً
[{"word":"ship","numSyllables":1},{"word":"shipp"},
 {"word":"schip"},{"word":"shep"},{"word":"shupp"}…]

GET /words?sl=ship&md=r&max=5     ← md=r يضيف النطق
[{"word":"shipp","tags":["pron:SH IH1 P "]}]
```

### 🔎 ملاحظة صادقة من الاختبار

النتائج تحتوي **أسماء أعلام وكلمات نادرة** (`shipp` · `schip` · `schep`).
هذه ليست صالحة للعرض على متعلم مبتدئ كما هي.

**الحل الإلزامي:** لا تستخدم ناتج Datamuse مباشرة. مرّره على قائمة الكلمات
الشائعة (البند 5) واحتفظ بما هو موجود فيها فقط. بدون هذا الفلتر، الأداة
تضرّ أكثر مما تنفع.

### الاستخدامات الحقيقية

| الحاجة | الاستعلام |
|--------|-----------|
| مشتتات اختبار ذكية | `rel_trg=` أو `ml=` (مرتبط بالمعنى) |
| كلمات على وزن صوتي | `sl=` (للأزواج الصغرى) |
| كلمات تقفّي | `rel_rhy=` (لدروس النطق) |
| عدد المقاطع | `numSyllables` في كل نتيجة |
| النطق ARPAbet | `md=r` |

**القيمة الأعلى:** مشتتات الاختبار. اليوم `QUIZ` يحتاج خيارات خاطئة معقولة؛
كلمة عشوائية من درس آخر مشتت ضعيف، وكلمة قريبة في المعنى مشتت حقيقي يُجبر
على التفكير.

## 3) 📖 ML Kit — على الجهاز · مجاني تماماً

مكتبات Google تعمل **محلياً بالكامل** — لا مفتاح، لا حصة، لا رفع بيانات.

### 3.1 التعرّف على النص (OCR)

```kotlin
// bundled: نموذج داخل التطبيق — يعمل فوراً بلا إنترنت (~4 MB لكل معمارية)
implementation("com.google.mlkit:text-recognition:16.0.1")

// unbundled: يُنزَّل عبر Play Services (~260 KB فقط)
implementation("com.google.android.gms:play-services-mlkit-text-recognition")
```

**الاستخدام:** قلب الفكرة 02 — صورة وحدة دولينجو → نص → درس.

### 3.2 كشف اللغة

```kotlin
implementation("com.google.mlkit:language-id:17.0.6")   // ~900 KB
```

**الاستخدام:** الصورة تحوي إنجليزية وعربية مختلطتين؛ هذه المكتبة تفصلهما
قبل تسليمهما لـ Gemini، فيصل النص مرتباً ويقلّ الخطأ.

### 3.3 الترجمة على الجهاز

**الاستخدام:** مسودة ترجمة فورية مجانية للكلمة — ثم Gemini يحسّنها عند
الحاجة فقط. جودتها أقل من Gemini، لكنها **مجانية وفورية وتعمل بلا إنترنت**.

### ⚠️ عقبة تقنية مهمة — يجب حسمها قبل التنفيذ

```
ML Kit (OCR وكشف اللغة) يتطلب:  minSdk = 23
Z-Mastery اليوم:                 minSdk = 24   ✅ متوافق
```

**لا مشكلة في الحد الأدنى.** لكن انتبه لأمرين:
1. **حجم التطبيق:** النسخة المُعبَّأة تضيف ~4 MB لكل معمارية. الأفضل للتطبيق
   الحالي: `unbundled` (~260 KB) مع معالجة حالة «جارٍ تنزيل النموذج».
2. **إذن الكاميرا غير موجود حالياً** في `AndroidManifest.xml` — سيلزم إضافته،
   أو الاكتفاء باختيار صورة من المعرض (أبسط وبلا إذن جديد على الإصدارات الحديثة).

## 4) 📖 Wikimedia / Wiktionary — أصول الصوت المرخَّصة

**الأهم لأجل [الفكرة 01](01-foundation-course.md).**

المشكلة التي يحلها: TTS لا ينطق الفونيم المفرد `/æ/` بشكل موثوق — ينطقه
كاسم حرف أو يفشل. القسم التأسيسي كله يقوم على هذا الصوت.

**الحل:** ويكيميديا كومنز تستضيف تسجيلات صوتية للفونيمات ولنطق آلاف الكلمات،
بتراخيص حرة (CC BY-SA / CC0).

```
واجهة الاستعلام:
https://commons.wikimedia.org/w/api.php?action=query&format=json
  &prop=imageinfo&iiprop=url&titles=File:{اسم الملف}
```

### الخطة المقترحة

```
① نزّل مرة واحدة: 26 اسم حرف + ~44 فونيماً إنجليزياً
② حوّل إلى صيغة موحّدة صغيرة
③ ضعها في app/src/main/res/raw/   ← 3 ملفات فقط هناك اليوم
④ اذكر المصدر والترخيص في شاشة «حول»
```

**النتيجة:** أصوات التأسيس تعمل **بلا إنترنت · بلا حصة · بجودة ثابتة إلى الأبد**.
هذا هو المرشح الأقوى لأول تنفيذ تقني من هذا الكتالوج.

## 5) 📖 قوائم التكرار والمستوى

ليست واجهات — **ملفات بيانات** تُضاف مرة وتُستخدم للأبد.

| المصدر | ما يعطيه |
|--------|----------|
| قوائم مستويات CEFR المفتوحة | تصنيف A1/A2/B1… لكل كلمة |
| قوائم تكرار من متون مفتوحة | ترتيب الكلمات بالأكثر شيوعاً فعلياً |
| قوائم تكرار الترجمات/الأفلام | الشيوع في **الكلام** لا الكتابة — أنسب للمحادثة |

### لماذا تهم فعلاً

1. **ترتيب المنهج التأسيسي:** لا تُدرّس حرفاً بكلمة نادرة. رتّب الأمثلة
   بالتكرار الحقيقي.
2. **شارة مستوى على كل كلمة:** `A1` · `B2` — يعرف المتعلم موقعه.
3. **فلتر Datamuse الإلزامي** (البند 2): يستبعد `shipp` و`schep`.
4. **إجابة مباشرة على «لا أشعر بتقدم»:**
   > «تعرف 340 من أول 1000 كلمة الأكثر شيوعاً — 34%»
   هذا رقم يقيس **إتقاناً**، لا حضوراً. وهو بالضبط ما يفتقده عدّاد الأيام.

**التنفيذ:** ملف JSON/CSV في `assets/` — بلا شبكة إطلاقاً.

## 6) 📖 Tatoeba — جُمل ثنائية اللغة

**النموذج:** ليست API حية — **تنزيل CSV** (`downloads.tatoeba.org`).
ملايين الجمل بترجماتها، بترخيص CC BY 2.0 FR.

**الاستخدام:** جمل EN–AR قصيرة لتدريب النطق بعد التأسيس.

**⚠️ تحذير جودة:** المحتوى من متطوعين — الترجمات العربية **متفاوتة الجودة**
بشدة. لا تُدخِل أي جملة دون مراجعة. القيمة محدودة لأن Gemini يولّد جملاً
أفضل وأنسب للسياق عند الطلب.

**الحكم:** ★☆☆ — احتياطي فقط.

## 7) ❌ ما نرفضه صراحةً

| الأداة | لماذا لا |
|--------|----------|
| `duolingo-api` (كلمة سر) | ❌ **خطر أمني** — لا تُدخل كلمة سر دولينجو في تطبيق ثالث أبداً |
| كتابة XP إلى دولينجو | ❌ **غش** — يزوّر التقدم ويناقض هدف التطبيق |
| Forvo API | ❌ مجانيته محدودة جداً · dictionaryapi.dev يغطي الحاجة بلا مفتاح |
| DeepL / Google Translate API | ❌ مدفوعان · Gemini وML Kit يغطيان الترجمة |
| ElevenLabs وأخواتها | ❌ مدفوع · Gemini TTS يعمل جيداً بالفعل |
| Oxford / Merriam-Webster API | ❌ يتطلبان مفتاحاً وتسجيلاً وحدوداً · القاموس المفتوح كافٍ |
| خدمات تقييم النطق التجارية | ❌ مدفوعة · `SpeechCapture.kt` موجود ويعمل |

**المبدأ الحاكم:** لدينا Gemini للذكاء، وSpeechRecognizer للنطق، وTTS للصوت.
أي أداة جديدة يجب أن **توفّر حصة** أو **تعطي ما لا يعطيه أي منها** —
وإلا فهي تعقيد بلا مقابل.

## 8) ترتيب التجريب المقترح

> بعد استقرار الإصلاحات الأساسية فقط.

```
① أصوات الحروف والفونيمات المحلية   (بند 4)
   → يفتح القسم التأسيسي · بلا شبكة · بلا حصة · أعلى قيمة

② القاموس المفتوح مع كاش دائم        (بند 1)
   → IPA وصوت بشري مجاني · يخفّض استهلاك Gemini فوراً

③ OCR للصورة                         (بند 3)
   → يفتح أسلوب الوحدة — بعد نجاح التجربة اليدوية في الفكرة 02

④ قوائم التكرار والمستوى             (بند 5)
   → يرتّب المنهج ويعطي مقياس «كم أعرف فعلاً»

⑤ Datamuse للمشتتات                  (بند 2)
   → يحسّن الاختبارات · يتطلب الفلتر من ④ أولاً
```

**لاحظ:** «شعلة دولينجو» ليست في القائمة. البند الأول لا يمسّ دولينجو
إطلاقاً — يبني ما لا يوفّره دولينجو أصلاً.

## 9) مبادئ ثابتة لأي تكامل خارجي

1. **الكاش إلزامي.** كل استجابة تُحفظ على القرص. الكلمة تُطلب مرة واحدة.
2. **الفشل صامت.** انقطاع الشبكة لا يُظهر خطأً — يعرض المتاح فقط.
3. **مجاني بلا مفتاح مُفضَّل.** كل مفتاح جديد = عبء إدارة وتسريب محتمل.
4. **على الجهاز يسبق السحابة.** ML Kit وملفات `res/raw` قبل أي طلب شبكة.
5. **الترخيص يُحترم.** CC BY-SA يتطلب ذكر المصدر — في شاشة «حول».
6. **لا اعتمادية أساسية على مصدر غير رسمي.** المصادر الهشة للتزيين لا للبنية.
