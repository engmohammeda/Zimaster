# 🔥 دليل Firebase الكامل — من الإعداد حتى نشر الدروس لطلابك

> **هدف الدليل:** بعد اتباعه حرفياً ستصبح: مسؤولاً في تطبيقك، تنشر الدروس من داخل
> التطبيق نفسه، ويصل كل درس تلقائياً لكل طالب على جهازه، مع حفظ تقدمه في السحابة.
>
> **ملاحظة:** كل الأكواد جاهزة داخل التطبيق — ما تحتاجه فقط هو إعداد Firebase نفسه.

---

## 1) نظرة سريعة: كيف يعمل النظام؟

```
👑 أنت (المسؤول)                    📱 الطالب
─────────────────                  ─────────────────
أدوات المطور ← استيراد الدروس
       │
       ▼ اختيار ملفات JSON/ZIP أو لصق
       │
       ▼ «نشر سحابياً لجميع الطلاب»
       │
   ☁️ Firestore                    يفتح التطبيق ← مزامنة صامتة
   /lessons/{id}         ────────► يسحب الدروس الجديدة تلقائياً
                                   (لا يرى زر استيراد إطلاقاً — محجوب للمسؤول فقط)
```

- **الطالب لا يستورد شيئاً أبداً** — كل الاستيراد محجوب عن غير المسؤول.
- تقدم الطالب (دروس مكتملة + كلمات + سلسلة) يُحفظ تلقائياً في `/users/{uid}/progress`
  ويُستعاد عند تسجيله من أي جهاز **بالدمج الآمن** (لا يمكن أن تُمسح بياناته).
- لوحة الصدارة العامة في `/leaderboard` (بدون إيميلات) والإعلانات في `/announcements`.

## 2) الإعداد لمرة واحدة على جهازك (10 دقائق)

### 2.1 تثبيت أدوات Firebase
```bash
npm install -g firebase-tools
firebase --version        # يجب أن يطبع رقم إصدار
```

### 2.2 تسجيل الدخول بحسابك (نفس بريد مالك المشروع)
```bash
firebase login
```
سيفتح المتصفح → سجّل بحساب Google المالك للمشروع (`zmastery`).

### 2.3 النشر من داخل مجلد المشروع
```bash
cd Zimaster
firebase use zmastery                       # أو: firebase use --add واختر المشروع
firebase deploy --only firestore:rules,firestore:indexes
```
**ماذا فعل هذا الأمر؟**
- نشر **قواعد الأمان المصلحة** (`firestore.rules`): تسمح للمسؤول فقط بنشر الدروس/
  العبارات/الإعلانات، وتمنع أي محاولة انتحال صلاحيات، وتحمي بيانات كل مستخدم لنفسه.
- نشر **الفهرس** المركّب للإعلانات.

### 2.4 تحقق سريع من نشر القواعد
```bash
firebase firestore:rules     # يطبع القواعد المنشورة فعلياً
```
أو من المتصفح: **Firebase Console ← Firestore Database ← Rules** — يجب أن ترى
في الأعلى سطر التعليق `Dusk` … لا، يجب أن ترى `Z-Mastery Firestore Security Rules`
مع `isSuperAdminToken`.

## 3) تفعيل طرق الدخول (Console — مرة واحدة)

من المتصفح: **console.firebase.google.com ← مشروع zmastery**

| البناء | Authentication ← Sign-in method | فعّل |
|--------|--------------------------------|------|
| حسابات البريد | Email/Password | ✅ Enable |
| حسابات Google | Google | ✅ Enable |
| الزوار (مهم للمزامنة!) | Anonymous | ✅ Enable |

> ⚠️ **Anonymous ضروري**: بدونه لن يستطيع التطبيق إنشاء جلسة سحابية للمستخدم الجديد،
> فلن تصلهم الدروس ولن يُحفظ تقدمهم.

وللدخول بحساب Google من نتيجة الاختبار يجب إضافة **SHA-1** لتطبيقك:
Authentication ← Settings ← Authorized domains / أو
Project settings ← Your apps ← Android ← Add fingerprint:
- SHA-1 الخاص بـ debug keystore: `cd Zimaster && keytool -list -v -keystore debug.keystore -alias androiddebugkey -storepass android | grep SHA1`

## 4) أن تصبح مسؤولاً داخل التطبيق (خطوتان)

1. **ثبّت نسخة هذا الفرع** (ادمج PR #6 ثم حمّل الـ APK من GitHub Releases وبمّله).
2. **سجّل الدخول بحسابك المالك** `mohammedalbkhyty@gmail.com` (بريد + كلمة مرور من
   شاشة الدخول، أو Google).
   - عند أول دخول يكتب التطبيق تلقائياً `role = "admin"` في `/users/{uid}` —
     القواعد تثق بهذا الإيميل لأنه يأتي من Firebase Auth موثّقاً.
3. **تحقق:** الإعدادات ← سترى قسم «👑 صلاحيات المطور والمسؤول» + قائمة الطلاب +
   الإعلانات. وسيظهر زر الاستيراد في كل مكان (الشريط العلوي، المزيد، الإعدادات).

> 💡 كود `ADMIN2026` يفعّل **وضع مطور محلي** فقط (لأدوات الواجهة) — صلاحيات
> **النشر السحابي** تأتي حصراً من تسجيل الدخول بحسابك المالك. هذا تصميم أمني مقصود.

## 5) نشر الدروس لطلابك (سير العمل اليومي)

1. افتح **المزيد ← استيراد الدروس** (تظهر لك وحدك).
2. ارفع ملفات `JSON` (أو ملف `ZIP` يحوي عدداً منها) أو الصق كود JSON مباشرة.
3. سيتعرف التطبيق على الدروس ويعرض عددها ومحتواها — **لن يُرفع شيء بعد**.
4. راجع، ثم اضغط **«👑 نشر N درس سحابياً لجميع الطلاب 🚀»**.
   - (زر «إضافة إلى المكتبة المحلية» يضيفها على جهازك فقط — مفيد للتجربة الشخصية.)
5. بعد ثوانٍ: رسالة نجاح تعني أنها في `/lessons` — **كل طالب يفتح تطبيقه سيسحبها فوراً**.

### تحديث درس منشور مسبقاً
أعد نشر نفس الدرس بنفس `course_id` ورقم `lesson_no` — التطبيق يكتب فوق نفس المستند
بتوقيت أحدث (`updated_at`) فتسحبه أجهزة الطلاب في أول فتح كتحديث.

### صيغة الدرس (JSON)
استخدم نفس الصيغة التي تصنعها بأداة الاستخراج الموحدة
(`UNIFIED_LESSON_EXTRACTOR_MASTER_PROMPT.md` في جذر المشروع):
`metadata.course_id` + `metadata.lesson_no` هما هوية الدرس السحابية.

## 6) تجربة المسار كاملاً (5 دقائق)

| # | الخطوة | النتيجة المتوقعة |
|---|--------|------------------|
| 1 | سجّل دخولك بحساب المالك | قسم 👑 ظاهر في الإعدادات |
| 2 | انشر درساً واحداً | رسالة نجاح + ظهوره في Firestore ← `/lessons` |
| 3 | على جهاز آخر (أو بعد مسح بيانات التطبيق) سجّل كطالب بريد جديد | **لا زر استيراد في أي مكان** |
| 4 | أغلق التطبيق وافتحه من جديد | الدرس المنشور يظهر تلقائياً في المستويات |
| 5 | أكمل الطالب درساً وأغلق وفتح | التقدم باقٍ + `/users/{uid}/progress` محدّث |
| 6 | من جهازك: الإعدادات ← قائمة الطلاب | الطالب ظاهر بإحصائياته |

## 7) أين أرى البيانات في الكونسول؟

| المسار | المحتوى |
|--------|---------|
| `/lessons` | دروسك المنشورة (حقل `json` يحوي الدرس كاملاً) |
| `/users/{uid}` | ملف كل مستخدم (اسم، دور، إحصائيات، آخر نشاط) |
| `/users/{uid}/progress/state` | نسخة تقدمه الاحتياطية (JSON بلا مفاتيح API) |
| `/leaderboard/{uid}` | مرآة إحصائيات عامة بلا إيميل (للوحة الصدارة) |
| `/quotes` | عبارات التحفيز التي تضيفها (تظهر بالودجت) |
| `/announcements` | إعلاناتك العامة |

## 8) حل المشاكل الشائعة

| المشكلة | السبب | الحل |
|---------|-------|------|
| «فشل النشر السحابي: PERMISSION_DENIED» | القواعد القديمة ما زالت منشورة | نفّذ الخطوة 2.3 |
| النشر يفشل رغم القواعد الجديدة | لم تسجّل الدخول بحساب المالك | سجّل بـ `mohammedalbkhyty@gmail.com` ثم أعد المحاولة |
| الطالب لا يستلم الدروس | Anonymous معطّل، أو المزامنة متوقفة من إعداداته | فعّل Anonymous (خطوة 3) |
| دخول Google يعطي رمز 10 | SHA-1 غير مسجل في Firebase | أضف بصمة SHA-1 (خطوة 3) |
| تقدم الطالب ضاع بعد تغيير الجهاز | لم يسجّل دخولاً (جلسة مجهولة لا تنتقل) | سجّل دخوله بنفس البريد/حساب Google |
| لوحة الصدارة فارغة | تُبنى تلقائياً عند أول مزامنة لكل مستخدم | افتح التطبيق مرة على الأقل ككل مستخدم |

## 9) الأوامر الجاهزة (نسخ ولصق)

```bash
# إعداد أول مرة
npm install -g firebase-tools && firebase login
cd Zimaster && firebase use zmastery

# نشر القواعد والفهارس (بعد أي تعديل عليها)
firebase deploy --only firestore:rules,firestore:indexes

# مراقبة ما ينشر لحظياً (اختياري)
firebase firestore:watch --project zmastery
```
