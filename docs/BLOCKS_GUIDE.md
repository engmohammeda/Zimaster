# 🧩 دليل نظام البلوكات — التغطية الحالية وبروتوكول المحتوى الجديد

> المرجع الدائم عند: إضافة نوع محتوى جديد · ظهور قسم لا يعرضه التطبيق · إضافة كورس جديد.

---

## 1) القاعدة الأساسية

**المحتوى يقود الواجهة، لا نوع الكورس.** كل درس يتحول إلى قائمة بلوكات
(`LessonBlocks.visibleBlocks`)، وكل بلوك يظهر **فقط إذا وُجدت بياناته** — لا أقسام فارغة
أبداً. دور الكورس: اللون + الأيقونة + ترتيب البلوكات.

## 2) مصفوفة التغطية (كل أنماط الكورسات)

| النمط | الآلية | البلوكات الفعالة |
|-------|--------|------------------|
| VOCAB_CARDS · من الصفر · Bites | ترتيب مخصص | جمل أساسية ← بطاقات مفردات ← ملاحظات ← اختبار |
| GRAMMAR_RULES | ترتيب مخصص | القاعدة+المنطق ← الأمثلة ← مفردات ← اختبار |
| CONVERSATION | ترتيب مخصص | حوار (تشغيل الكل) ← تعبيرات ← مفردات |
| READING_TEXT | ترتيب مخصص | «استمع للنص كاملاً» ← مقاطع/نص كامل ← مفردات |
| PHONETICS_SOUNDS | ترتيب مخصص | أصوات+أزواج+تدريب (rawJson) ← مفردات |
| WRITING_PRACTICE | ترتيب مخصص | عصف ذهني ← جمل موجّهة ← مسودتك ← النموذجية |
| LISTENING_AUDIO | افتراضي | «استمع للنص كاملاً» ← مقاطع بصوت ← حوار إن وجد |
| STORY · NEWS · COMEDY · CULTURE · THINKING | افتراضي | نص+صوت+ترجمة ← مفردات ← ملاحظات ← اختبار |
| IDIOMS | افتراضي | تعبيرات بصوت ← مفردات ← اختبار |
| EXAM_PREP / IELTS | افتراضي | قراءة ← ملاحظات ← اختبار (شامل النوع الكتابي WRITTEN) |

**اختبار الدرس يدعم**: اختيار متعدد · صح/خطأ · كتابي · سماعي (يُنطق قبل الإجابة).

## 3) شبكات الأمان المدمجة

1. نمط غير معروف → `DEFAULT_ORDER` (يعرض كل ما له بيانات — لا انهيار).
2. نوع سؤال غير معروف → يسقط آمناً على «اختيار متعدد».
3. `rawJson` يُحفظ **حرفياً** مع كل درس → أي قسم لم يعد له بلوك اليوم يبقى محفوظاً
   ويعرض مستقبلاً بمجرد إضافة البلوك — **شفاء رجعي لكل الدروس المنشورة سلفاً**
   دون إعادة نشر المحتوى.
4. القواعد المتعددة (المخطط القديم) تُطوى تلقائياً في «النقاط الرئيسية» — لا فقدان.

## 4) بروتوكول المحتوى الجديد («المفاجآت»)

```
المستوى 0 — قسم جديد بحقول معروفة (نص/جمل/حوار/كويز/تعبيرات/ملاحظات…)
   ⟶ لا شيء مطلوب: يُعرض تلقائياً.

المستوى 1 — كورس جديد كلياً بنمط غير معروف
   ⟶ يعمل فوراً بالترتيب الافتراضي.
   ⟶ للترقيه: أضف سطر key→style في ImportController.styleFor + شارة/لون في
     SampleData (لو كورس منهجي) — لا شاشات ولا تعديلات أخرى.

المستوى 2 — تفاعل جديد جوهرياً (فيديو · توصيل · فراغات · بطاقات قلب…)
   ⟶ القاعدة الذهبية: أضف «بلوكاً واحداً» يخدمه هو وغيره، بثلاث خطوات:
       ① قيمة في LessonBlockKind
       ② شرط ظهور في LessonBlocks.visibleBlocks (وجود البيانات فقط)
       ③ ملف Composable واحد داخل ui/screens/lessons/blocks/
   ⟶ لا تُنشأ شاشة جديدة لأي محتوى — شاشة الدرس الموحدة تستضيف الجميع.
```

### حالة جاهزية موثقة: التسجيلات الصوتية الأصلية (audio_url)
المخطط القديم يقبل `audio_url`/`video_url` لكن التطبيق حالياً يعتمد توليد الصوت
(Gemini TTS) لكل عنصر. إذا وردت دروس بتسجيلات أصلية مطلوبة:
1. أضف `audioUrl: String = ""` إلى `LessonDto` + `Lesson` + المخططات (`Mappers`).
2. أضف بلوك `AUDIO_PLAYER` واحداً (مشغل URL بسيط) يظهر فقط عند وجوده.
3. rawJson يجعل كل الدروس المنشورة سلفاً تدعمه فوراً.

## 5) فحص قبول عند إضافة أي بلوك جديد

- [ ] يختفي تماماً حين لا توجد بياناته (لا بطاقات فارغة)
- [ ] يعمل بوضعي الفاتح/الغامق وبنظام Dusk Indigo (رموز ZRadius/ZSpace)
- [ ] لا يجمّد الواجهة مع 25+ عنصراً (LazyList items بمفاتيح ثابتة)
- [ ] لا يكسر ترتيب أي نمط موجود (أضفه لـ DEFAULT_ORDER فقط — التخصيصات تتكفل بالباقي)
